# ALLai

Единый интерфейс для работы со всеми ИИ мира.

## Возможности

- **Меню ИИ** — список популярных моделей (ChatGPT, Claude, Gemini, Grok, Llama, Mistral, DeepSeek, Qwen, Kimi, Perplexity и другие).
- **Выбор моделей** — можно выбрать одну, несколько или все модели.
- **Режим ALL** — включает все ИИ сразу: модели работают вместе и формируют единый синтезированный ответ.
- **Чат-интерфейс** — отправляйте запросы и получайте ответы от выбранных ИИ.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```
